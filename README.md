# GravityGardens-SMH
This repository is for the Project Gravity Gardens Small Hypergravity Machine. 
# How to setup the ESP32 for Arduino IDE
Refer to this [guide](https://randomnerdtutorials.com/installing-the-esp32-board-in-arduino-ide-windows-instructions/).
# Libraries Needed for DHT22 Example
These are the libraries needed to upload the code
  1. [Arduino Unified Sensor](https://github.com/adafruit/DHT-sensor-library/archive/master.zip)
  2. [DHT Library](https://github.com/adafruit/DHT-sensor-library/archive/master.zip)
  3. [ESPAsyncWebServer](https://github.com/me-no-dev/ESPAsyncWebServer/archive/master.zip)
  4. [ESPAsyncTCP](https://github.com/me-no-dev/AsyncTCP/archive/master.zip)
  5. [LittleFS](https://randomnerdtutorials.com/arduino-ide-2-install-esp32-littlefs/) (Refer to the guide)
