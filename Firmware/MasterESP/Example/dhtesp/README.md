# Firmware

This is the firmware for the ESP32. Just a test of the website, DHT22 sensors and file seperation.

The file system uploader used is called LittleFS. This [guide] (https://randomnerdtutorials.com/esp32-littlefs-arduino-ide/) can get you set up for it.

LittleFS allows the HTML, CSS and JavaScript to be uploaded and accessed on the ESP32. 



The Embedded Systems documentation can be found [here](https://docs.google.com/document/d/1yqqiMzjETktpeUCmVOw1XjPWxqupdX1V/edit?usp=sharing&ouid=112255443107490151474&rtpof=true&sd=true)
